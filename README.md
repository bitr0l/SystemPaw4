# The SystemPaw4 Operating System

SystemPaw is a very needy operating system for critters who like to play !! It serves as a horny way to manage machine
resources, I/O and userspace requests. It is inspired by old mainframe operating systems but aiming to have a polished
design.

## No AI / LLMs

SystemPaw4 is written by paw from hardworking critters who want to provide top quality sources, therefore the usage
of LLMs / AI is prohibited.
